# Changelog

All notable changes to this project are documented here. The format follows [Keep a Changelog](https://keepachangelog.com/en/1.1.0/) and the project uses [Semantic Versioning](https://semver.org/).

## [Unreleased]

### Fixed
- Captions covered faces in the Remotion renderer: the caption offset was a percentage of the frame *width*, so on 9:16 the text sat about a third of the way down, on the speakers' faces. Both renderers now centre each caption page on a height fraction (default lower third: 72%, 76% for `clean`). Emphasised words in Remotion no longer run into the next word.

### Added
- `oneclip-hooks` agent skill: how to find clips that get watched. It covers what a hook must do in the first 1–3 seconds, 12 hook types mapped to Jev's hook types, five text-hook formulas, a scoring rubric with three gates, moving the hook to the front (cut the setup, cold open, mid-story drop, reaction first), on-screen text hooks, playbooks for 10 kinds of source, length and frame per platform, hook variants, mistakes, a pre-render checklist and what to measure after posting. A zero-dependency scanner (`skills/oneclip-hooks/scripts/find-hooks.mjs`) ranks hook lines in a project's transcript, adds Jev's live scores and flags hooks that land late. Installed with the other skills by `pnpm skills`.
- Face-safe captions: before rendering, OneClip runs a small local face detector (YuNet, MIT, 233 kB, downloaded once from Hugging Face and hash-checked) on three frames of every shot and moves any caption page that would touch a face to the nearest clear spot for the chosen frame shape and layout. No model or no network: captions stay in the default lower third.
- Agent skills on clone: OneClip installs the `oneclip-editor` skill and every skill from the 17 motion-graphics repos in `skills/motion-skills.json` (HyperFrames, Remotion skills, LottieFiles motion design, animate, claude-motion and more) into `.claude/skills/` and `.agents/skills/`. Claude Code does it on its first session in the folder (`SessionStart` hook); other agents are told to run `pnpm skills` by the new `AGENTS.md`; `pnpm run setup` runs it too. The editor skill now says where caption placement lives and which motion skills to use for it. Each repo is pinned to a reviewed commit in the manifest: a push upstream reaches nobody until a PR moves the pin (`pnpm skills --latest --pin`). `--if-missing` redoes only failed or re-pinned repos, and skills that pre-approve tools or add hooks are flagged.
- Content-aware ranking: OneClip detects what the source is (music video, song, podcast, talk, stream, gameplay, film, vlog, sports or footage) from the page's title, tags, category and live status and from the sound and picture, or you pick it (web form "Content type", `pnpm clip --content`). Jev gets a guide for each type that says what the best clip is, plus where each clip sits in the source. In music videos and songs, OneClip finds the song span (dense, loud audio, from a new per-second loudness-variation signal) and the chorus (lyrics that repeat 20+ s apart). Candidates open only inside the song, and the chorus gets a lift. A skit, intro or outro outside the song scores ×0.55, and openings with greetings or sponsor reads score ×0.75. The project page and the CLI show what was detected and why. Existing projects re-score once because the Jev request changed.
- English captions for any language: a new Captions option (`english`, the default; `original`; `off`) in the web app and `pnpm clip --captions`. For links, OneClip first uses the site's English subtitles (the uploader's own track, then the site's auto-translation) — for a Korean music video that is the official English lyrics. Without them it translates the audio to English with Whisper (`--task translate`). Cuts still follow the spoken words; only the caption text changes. The project's transcript line says where the captions came from.
- Hooks in any kind of media: a new "signals" stage measures loudness and visual change per second with FFmpeg, classes the source as speech, music or visual, and adds sound/picture "moments" (drops, choruses, hits, cuts, motion) next to spoken passages. Jev sees each clip's sound and picture and has two new hook types, `sonic_drop` and `visual_spectacle`. Silent videos and instrumentals now work instead of failing. Existing projects re-score once because the Jev request changed.
- Automatic clips folder: finished 1080p clips are saved to `clips/<video-title>-<id>/<rank>-<clip-title>.mp4` in the OneClip folder (made on first use, git-ignored), shown on the Exports page and printed by `pnpm clip`. `ONECLIP_CLIPS_DIR` moves it.
- Links as input: paste a YouTube link or a link from any site yt-dlp supports (other video platforms, SoundCloud, podcast pages, direct media URLs). OneClip downloads it (best quality up to 1080p) in the analyze job, with progress, and uses the page's title. yt-dlp is found on PATH or installed with pip on first use.
- Audio and podcasts: MP3, M4A, WAV, AAC, FLAC, OGG, Opus and WMA files (and audio-only links) become a 1080×1080 video of the cover art over a blurred background, then clip like any video. More video containers accepted (M4V, AVI, WMV, FLV, TS, MTS, MPG, 3GP, OGV).
- Project scaffold: MIT licence, README, contributing guide, code of conduct, security policy, issue and PR templates, CI.
- Core pipeline: FFprobe/FFmpeg ingestion, local transcription (faster-whisper with an ONNX Whisper fallback), sentence-aligned candidate clips with four length presets.
- Jev hook ranking through the One CLI: six weighted scores, a context-integrity gate, hook types, penalties, de-duplication, top N, SQLite cache.
- Evaluation harness (`pnpm eval:hooks`) with synthetic datasets and local good/average/bad feedback.
- OpenRouter edit planner through One (`one actions execute open-router`), on cheap models with JSON output and fallbacks; the default for `auto`.
- Edit planners (Claude Code, OpenCode, deterministic template) with Zod-validated plans and automatic fallback.
- Renderers: Remotion (three templates, word-by-word captions, 1080×1920 at 30 fps) and FFmpeg (ASS captions), with FFprobe output checks and an FFmpeg fallback.
- Local web app: Setup, Video input, Processing, Hook results (live Remotion preview), Exports (per-clip download and zip).
- `pnpm run setup`, `pnpm run doctor`, `pnpm clip`, `pnpm e2e`, and a resumable media worker.
